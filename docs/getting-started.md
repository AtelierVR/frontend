# Getting Started

## Prerequisites

- Node.js 20+
- A running [NoxVR Node](https://github.com/AtelierVR/node) instance

## Installation

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment

Create a `.env.local` file:

```env
NEXT_PUBLIC_API_URL=http://localhost:3042
```

## Docker

```bash
docker-compose up -d
```
